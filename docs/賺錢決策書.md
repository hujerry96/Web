## 2. 路徑 A：網站 SEO + 材料科學內容（主線）

### 2.1 為什麼選材料科學？

這是整個策略的核心前提——**你選了一個 AI 難以取代的利基**。

| 面向 | 優勢 |
|------|------|
| **專業門檻** | 材料科學需要真實專業知識，AI 泛泛而談騙不了行家 |
| **競爭環境** | 材料科學 SEO 內容的競爭者遠少於「理財」「旅遊」「3C 開箱」 |
| **讀者價值** | 專業讀者願意為高品質內容付費（$10-20 PDF 不是問題） |
| **變現路徑** | 文章 → 免費資源 → Gumroad 完整產品，天然漏斗 |

### 2.2 關鍵字研究：第一優先

你選擇用 **Google Keyword Planner**。具體做法：

```
步驟 1：申請 Google Ads 帳號（如已有則跳過）
        └→ 進入工具 → 關鍵字規劃工具

步驟 2：輸入種子關鍵字
        └→ materials science
        └→ SEM analysis
        └→ XRD analysis
        └→ thermodynamics materials
        └→ materials characterization
        └→ 以及你專業領域的任何相關詞

步驟 3：分析結果
        └→ 關注「月搜尋量 100-1,000」且「競爭低」的關鍵字
        └→ 這是你的黃金區間——有人搜但不擁擠

步驟 4：分類建檔
        └→ 將關鍵字分組到不同 Pillar 下
        └→ 每個 Pillar 至少 5-10 個可用關鍵字
```

**預估耗時：2-3 小時。** 這份研究結果將決定你接下來 6 個月的內容方向，值得投入時間。

### 2.3 內容 Pillar 策略

關鍵字研究完成後，將關鍵字分組到以下 Pillar 中。以下是「可能性範例」——實際 Pillar 以關鍵字研究結果為準：

```
Pillar A：材料分析技術（SEM, XRD, EDS, XPS, AFM…）
    └→ 你的 SEM 分析工具文章已在這個 Pillar 中

Pillar B：機械測試（拉伸、硬度、疲勞、斷裂力學…）

Pillar C：熱分析（DSC, TGA, DMA, 熱膨脹…）

Pillar D：材料科學學習方法（Study Guide, Exam Prep…）

Pillar E：實驗室管理（Lab Notebook, Data Management…）
```

**每個 Pillar 的標準操作流程：**

```
Pillar 確認 → 列出 5-10 篇關鍵字文章 → 依序撰寫
    ↓
每 3-4 篇文章 → 彙編成一份 Gumroad PDF 完整指南
    ↓
在文章中嵌入免費版 PDF（非完整內容）引導至 Gumroad
```

### 2.4 文章到 Gumroad 產品漏斗

```
網站文章（免費）
    │
    ├─ 內文嵌入：免費版 PDF 下載連結（需 Email）
    │   └→ 收集 Email 名單（未來可轉換為付費客戶）
    │
    ├─ 文末 CTA：「完整版 PDF 包含進階內容 + 模板 → Gumroad」

## 3. 路徑 B：Gumroad 數位產品

### 3.1 Gumroad vs Amazon KDP 比較

| 面向 | Amazon KDP | Gumroad |
|------|-----------|---------|
| **內建流量** | ✅ 上百萬人搜尋 | ❌ 無，需自行導流 |
| **佣金抽成** | 35-65% 給 Amazon | Gumroad 抽 3-10% + $0.30 |
| **客戶名單** | ❌ 你不知道誰買了 | ✅ 你可以收集 Email |
| **產品格式** | 限 Kindle 電子書 | 任何數位檔案（PDF, 模板, 軟體…） |
| **定價自由** | $0.99-$9.99 常見 | $1-$200+ 都行 |
| **上架速度** | 審核 24-72 小時 | 立即上架 |
| **適合** | 有搜尋量的消費型產品 | 有流量的專業型產品 |

**你的情況：**
- 材料科學是專業利基（搜尋量小但精準）→ **Gumroad 更適合**
- 你已經有網站但沒流量 → 先用 SEO 養流量，流量來了 Gumroad 自然能賣
- 4 本 PDF 已準備好 → 先上架再說，零成本

### 3.2 第一批 Gumroad 產品

現有 4 本材料科學 PDF，已有封面，可直接上架：

| PDF | 建議 Gumroad 標題 | 建議定價 |
|-----|-------------------|:--------:|
| MaterialsScienceNotes.pdf | Materials Science Study Notes – Core Concepts & Formulas | $12 USD |
| Thermodynamics Study Guide.pdf | Thermodynamics for Materials Scientists – Study Guide | $15 USD |
| Materials Characterization Lab Notebook.pdf | Materials Characterization Lab Notebook – Structured Templates | $15 USD |
| Semiconductor Process Lab Notebook.pdf | Semiconductor Process Lab Notebook – Engineer's Log | $12 USD |

**上架步驟（每本 15 分鐘）：**

```
1. 登入 Gumroad → Create Product
2. 上傳 PDF + 封面圖
3. 設定價格（$10-20 USD）
4. 寫產品描述（說明這是給誰用的、包含什麼）
5. 設定 License Key 或直接下載
6. 發布 → 取得 Gumroad 連結
7. 把連結貼回網站對應文章中
```

### 3.3 後續產品線規劃

第一批上架後，產品線應該持續擴充：

```
產品線 1：學習指南（高頻）
    └→ 文章 → 整理為 PDF → Gumroad
    └→ 每 1-2 週可產出一個

產品線 2：模板工具（中頻）
    └→ Lab Notebook 模板（Notion / Excel）
    └→ 論文格式模板
    └→ 實驗數據記錄表

產品線 3：軟體工具（低頻 — 目前延後）
    └→ 自動化分析腳本
    └→ 開發週期長，先不做
```

**產品倍增策略：**

文章內容本身就有雙重價值——先當 SEO 內容吸引流量，累積足夠篇數後彙整成完整指南賣錢。一篇好文章可以在兩個環節產生價值。

### 3.4 定價策略

你選擇 $10-20 USD 區間。這個價格區間在 Gumroad 上對專業教育類 PDF 非常標準。

```
$10-12：輕量級指南（15-30 頁）
$15-18：中量級指南（30-60 頁 + 模板）
$20+ ：完整手冊（60+ 頁 + 多個模板 + 範例）
```

**價格心理學：** 材料科學的學習資源在 Amazon 上也常定價 $9.99-$14.99。Gumroad 上因為抽成低，你拿到的實際收入反而更高。

```
