# 文章規格範本

> 這是一份完整的文章規格說明。後續每篇文章都會用這個格式產出一份 `.md` 檔案。

---

## 文章規格元素說明

### 1. 基本資料

| 項目 | 說明 |
|------|------|
| **文章 ID** | 唯一識別碼，用於檔案命名與內部參考 |
| **主題** | 一句話描述文章在講什麼 |
| **目標讀者** | 誰會搜到這篇文章、他們原本知道多少、想看什麼 |
| **文章類型** | 指南型（tutorial）、科普型（explainer）、比較型（comparison）、觀點型（opinion）、新聞分析型（news analysis） |
| **預計總字數** | 中英文版本各多少字 |
| **urgency** | 為什麼現在要寫這篇（時事熱度、搜尋趨勢上升中） |

### 2. SEO 策略

| 項目 | 說明 |
|------|------|
| **主要關鍵字** | 這篇文章要搶排名的主要關鍵字（1-2 個） |
| **次要關鍵字** | 文章中自然涵蓋的相關關鍵字（5-10 個） |
| **搜尋意圖** | 使用者搜尋這個關鍵字時想解決什麼問題 |
| **目標排名位置** | 第 1-3 頁？這取決於競爭強度 |
| **內部連結建議** | 網站上哪些既有文章可以互相連結 |
| **外部連結建議** | 引用權威來源（Nature、Science、學術論文）提升 E-E-A-T |

### 3. 文章大綱（H1 → H2 → H3）

完整的章節結構，每節標註重點與關鍵字涵蓋。

```yaml
---

```
