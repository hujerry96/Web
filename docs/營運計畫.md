# 營運計畫：Hu Lab + Hu Select 雙品牌

最後更新：2026-07-23

---

## 一、品牌架構

```
同一個 domain ─┬─ Hu Lab    理工知識內容 → KDP 賣書 + Amazon 分潤
               │             風格：專業、教育感
               │             色票：現有暖色羊皮紙
               │
               └─ Hu Select  綜合購物推薦 → 蝦皮/Amazon 分潤
                             風格：活潑、消費感
                             色票：需另行設計（同站、不同 theme）
```

### 技術實現

**同站不同色**（選項 1）：
- 共用同一套 Astro codebase
- Lab 與 Select 用不同的 CSS class 切換色票
- Header 已內建品牌切換功能（Lab/Select）
- Select 文章在 frontmatter 標記 `brand: select`，Layout 根據此標記載入不同 CSS

### SEO 策略

- 同一 domain，權重共享
- Lab 內容：策略性內部連結，建立 topical authority
- Select 內容：以長尾關鍵字 + 分潤轉換為目標，不需要建立深度權威
- 兩個品牌在 Google 眼中是同一站的不同主題分類

## 二、Hu Lab 內容策略

### 目標

- 建立「理工知識內容」的 SEO 權威
- 主要變現：導流到 KDP 材料科學/理工電子書
- 次要變現：Amazon 分潤（教科書、實驗設備、軟體）

### 內容 Pillars（理工全領域）

依序攻略。每個 Pillar 產出 4-8 篇互聯文章。

| Phase | Pillar | 主題 |
|:-----:|--------|------|
| P1 | A | 材料特性分析（SEM, TEM, XRD, DSC, TGA, FTIR） |
| P1 | B | 機械測試（拉伸、硬度、疲勞、斷裂力學） |
| P2 | C | 材料科學學習資源（考試準備、教科書推薦、Lab Notebook 指南） |
| P2 | D | 高分子與複合材料 |
| P2 | E | 金屬與熱處理（相圖、合金、熱處理工藝） |
| P3 | F | 半導體材料（能帶、摻雜、製程概覽） |
| P3 | G | 進階分析技術（EDS, XPS, AFM, DMA） |
| P4 | H | 其他理工延伸（視流量與需求決定） |

### 每篇文章 SOP（約 1 小時）

```
1. 關鍵字確認（5 分鐘）
   - 用 Keyword Planner 確認搜尋量與意圖

2. AI 產出初稿（20 分鐘）
   - Prompt 包含：關鍵字、目標讀者、語氣

3. 人工審稿 + 加入專業內容（20 分鐘）
   - 加入真實經驗/例子——這是跟其他 AI 站的差異化
   - 修正 AI 錯誤

4. 加入 KDP / Amazon 連結（5 分鐘）
   - 文章自然提及對應的 KDP 產品

5. 格式 + 圖片 + 發布（10 分鐘）
   - 示意圖、frontmatter、排程或發布
```

## 三、Hu Select 內容策略

### 目標

- 只要是有分潤可賺的主題都可以寫（不限領域）
- 主要變現：蝦皮分潤（台灣市場）
- 次要變現：Amazon 分潤（如果主題適合）
- 不求 SEO 權威，追求單篇轉換

### 選題框架

每篇 Select 文章前問自己這三個問題：

```
① 這個產品/主題的搜尋量存在嗎？
   → Google 搜尋看看有沒有人搜

② 有分潤計畫嗎？
   → 蝦皮有？Amazon 有？佣金多少？

③ 競爭者長什麼樣子？
   → 搜尋結果前 5 名是商城頁還是部落格文？
   → 部落格文的話，你寫得比他們好嗎？
```

**三個答案都是 YES → 寫。**

### 不限制主題，但有限制品質

- 禁止純產品規格貼上（沒有人想看 DM）
- 至少加入個人觀點或使用情境（即使不是真實體驗，也要寫得像真的經過思考）
- 標題要有搜尋意圖，而不是「ＸＸ開箱」

### 從現有文章延伸的主題池

| 現有主題 | 可延伸方向 |
|---------|-----------|
| 旅遊（京都指南） | 其他旅遊地點、行李、交通票券 |
| 生活用品（衛生紙、雨衣、電風扇） | 相同品類其他產品比較 |
| 3C（AirPods） | 其他藍牙耳機、充電配件 |
| 美妝（香水、手工皂） | 男性保養、沐浴用品 |
| 服飾（德比鞋） | 其他鞋款、搭配 |

## 五、時間管理

### 建議排程（7hr/週）

你選擇不固定輪替。但為了避免「這週忙」導致停擺，建議設一個底線：

| 規則 | 說明 |
|:---:|------|
| **最低產出** | 每週至少 2 篇文章（不分品牌），低於此數視為警示 |
| **雙週檢討** | 每兩週檢查一次：Lab 跟 Select 的文章比例是否偏離預期 |
| **月回顧** | 每月看一次 GSC 流量數據，決定下個月要壓哪一邊 |

### 時間分配的參考

如果你的時間當週比較充裕（7hr 全滿）：
- Lab 3 篇（約 3hr）+ Select 2 篇（約 2hr）+ 關鍵字研究 + 維護（約 2hr）

如果你的時間比較緊（3-4hr）：
- 全部用來寫 Lab，Lab 有長期 SEO 複利效應
- Select 文章隨時可補，但 Lab 需要持續累積
