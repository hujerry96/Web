# 2. 轉向材料科學權威站

日期: 2026-07-23

## 狀態

已決定

## 背景

原本網站採雙品牌散彈策略：Hu Lab（知識內容）＋ Hu Select（蝦皮分潤），內容橫跨旅遊、理財、料理、材料科學、運動解剖、生活開箱等不相關主題。經營者時間有限（7hr/週）、SEO 經驗零、預算零。

同時經營者在 Amazon KDP 已有成功經驗（單一產品曾達 $1,000+ 收入），其他 KDP 產品以材料科學為主。

## 決策

將網站從「綜合內容站」轉型為「材料科學（Materials Science & Engineering）權威站」：

1. 所有非材料科學內容不再產出
2. 現有非材料科學文章設 noindex，不影響主站 SEO
3. Hu Select 凍結，不再產出新分潤內容
4. 每週 7 小時全數投入材料科學內容產出與 SEO
5. 網站首要商業目的為 KDP 導流，次要為 Amazon 分潤

## 取捨

### 選擇這個的原因
- 經營者的理工科系背景與材料科學內容高度吻合，有 credibility
- 現有 KDP 產品（材料科學類）可直接透過網站導流變現
- 網站已有部分材料科學內容可沿用
- 材料科學在 SEO 中競爭度中等，繁體中文市場幾乎無人耕耘
- 7hr/週的資源只能聚焦一個 niche，分散必亡

### 不選擇的其他選項
- **醫學/運動健康站**：雖然有成功 KDP 產品（下肢運動傷害著色書），但經營者非醫學背景，YMYL 領域 SEO 難度高
- **維持散彈策略**：無法建立 topical authority，SEO 起不來，$2K/月目標不可能達成

## 影響

- 網站流量短期內可能下降（移除不相關內容）
- 需要處理現有排程中不相關文章的發布
- 中文 Hu Select 的 Shopee 分潤收入歸零（本來也接近零）
- 長期：主題聚焦 → SEO 權重累積 → 有機流量成長 → KDP 銷售提升
